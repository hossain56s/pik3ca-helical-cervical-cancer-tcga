To run PIK3CA_Helical_Hotspot_Analysis.ipynb, please download the TCGA-CESC Pan-Cancer Atlas 2018 dataset from cBioPortal:

Download cesc_tcga_pan_can_atlas_2018.tar.gz from cBioPortal.

Extract the following files into the same directory:

data_clinical_patient.txt

data_mrna_seq_v2_rsem.txt

data_mutations.txt

Run the Jupyter Notebook.
